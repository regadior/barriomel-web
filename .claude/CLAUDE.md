# barriomel-web

Shop window for BARRIOMEL, Rodrigo's own honey business. Catalogue plus direct contact by
WhatsApp and email.

Astro 7 · React 19 (one island) · Tailwind 4 · strict TypeScript · static output · GitHub Pages.

## Non-negotiables

- **No payment gateway, no cart.** Every sale closes person to person. A request for checkout
  is a change of business model: ask before building it.
- **Never invent business facts.** Prices, honey variety, flavour, location and contact
  details are Rodrigo's. Use an example value only while saying so out loud.
- **Zero JavaScript by default.** The home page ships 0 bytes and stays that way.
