# Routing and base path

The site is served from a subdirectory on GitHub Pages (`/barriomel-web` today, `/` once the
custom domain is live).

## Absolute paths

- **Never hand-write an absolute path** in markup: `href="/x"`, `src="/x"`, `url("/x")`. Astro
  does not apply `base` to string literals, so they 404 in production.
- Build every link through `src/lib/links.ts`: `linkTo`, `alternateLinks`, `absoluteUrl`,
  `publicAsset`.
- `site.basePath` and `site.url` in `src/data/site.ts` are the only source. Never read
  `import.meta.env.BASE_URL` in parallel with them.

## No server redirects

Pages has none, so the default locale carries no prefix:

| Page | Spanish | Galician |
| --- | --- | --- |
| Home | `/` | `/gl` |
| Products | `/productos` | `/gl/productos` |
| Contact | `/contacto` | `/gl/contacto` |

- Never reintroduce a prefix for the default locale, and never add a `/` → `/es` redirect.
- Generated by `src/pages/[...lang]/`, with `lang` set to `undefined` for Spanish.
- Slugs stay identical across locales on purpose. Translating them would need a route map for
  marginal SEO gain.

## Purity

- `localizedPath` and `alternatePaths` in `src/lib/i18n.ts` take the base path as a
  **parameter** so they stay pure and testable. `src/lib/links.ts` is what injects it.
- Pages receive `locale` as a typed prop from `getStaticPaths`. Never parse it out of the URL
  at runtime, and never cast a `string` to `Locale`.
