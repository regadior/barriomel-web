# Languages

Spanish and Galician. English was deliberately dropped.

## Dictionaries

- Zero visible text hardcoded in a component. Every string comes from the dictionary.
- `Dictionary` is **derived** from the Spanish dictionary (`typeof es`). Never hand-write a
  parallel `Dictionary` interface.
- **Never put `as const` on a dictionary.** It would freeze the strings into literal types and
  force Galician to repeat the Spanish text verbatim.
- Product- and photo-keyed sections are typed `Record<ProductId, string>` and
  `Record<PhotoKey, string>`, so a new product or photo fails the build until both languages
  have text.
- Alt text describes the photograph; it never repeats the heading.

## Galician

Real Galician, not Spanish with accents.

- `mel` is **masculine**: `o mel`, `mel cru`, `lévalo`.
- Use `colmea` (hive), `colmeal` (apiary), `colleita` (harvest), `castiñeiro` (chestnut),
  `pole` (pollen), `obradoiro` (workshop), `prezo` (price), `dispoñible` (available).
- Keep list lengths equal across languages so no section renders short. The tests assert this.
